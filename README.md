# AutoWagon — סימולטור עגלה אוטונומית

סכמטי אך ברור מספיק להשלמת פרויקט: עגלת קמפינג מתקפלת עם שתי תצורות הנעה, חיישנים, Follow-Me, נקודות דרך, מחשבון מומנט/הספק, BOM וחיווט.

**מידות אמבט:** 88 × 51 × 35 ס״מ · **גלגלים:** Ø17 × 10 ס״מ (לפי דף המוצר)

## תצורות
- **A** — מנוע יחיד + תיבה + דיפרנציאל/שרשרת + היגוי Ackermann
- **B** — 4 מנועי רכזת, skid-steer

## הפעלה מקומית
```bash
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```
